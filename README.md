# Movie Search and Record

A personal project for searching and recording movie information.

## Features

- Search for movies by title
- View movie titles, original titles, and release dates
- Record movies of personal interest
- Save TMDB movie IDs
- View movie ratings and popularity information

## Data Source

This project uses the [TMDB API](https://developer.themoviedb.org/) to obtain publicly available movie information.

The project is currently intended for personal learning, development, and movie information tracking. It does not provide full movie files, sell movie data, or offer paid services.

## TMDB Attribution

The rights to TMDB-related data and images belong to their respective rights holders. This project does not claim ownership of that data or those images.

## Configuration

Before using the project, apply for a TMDB API Read Access Token and configure the following environment variable:

`TMDB_READ_ACCESS_TOKEN=your_token_here`

Do not commit a real API Token to GitHub or any other public code repository.

## Usage

This project uses the TMDB API to search for movies and save movie records. Movie titles, release dates, ratings, popularity values, and other information are provided by TMDB.

Users should comply with TMDB API request limits and applicable terms of use.
